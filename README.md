# Belajar Inggris

Aplikasi belajar bahasa Inggris satu file (offline), Level 1-4 plus IELTS.

Menu: Kosakata (1.038 kata, kuis pilih arti, kuis kata yang pernah salah), Lengkapi kalimat, Grammar (88 topik), Baca cerita (51), Isi kotak (52), Dengar (80 situasi), Caption gambar, Kata saya.

Buka `index.html` di browser. Untuk membangun ulang dari sumber: `python3 build.py` (sumber ada di `src/`).
